# Embedded Software Engineering

**TU Dresden | 2025–2026 | Academic Laboratory Projects**

## Overview

This repository presents selected laboratory projects from my Software Engineering Vertiefung coursework at Technische Universität Dresden.

The projects involved embedded programming, control systems, hardware interfaces and software development in C/C++.

The source code and complete solutions are kept private because the laboratory assignments are reused for teaching purposes.

---

## 1. Automatic Door Control — ART-1

**Technologies:** C, Finite State Machines, SDL2

Development of control logic for an automated motorized door.

**Main topics:**
- Finite state machine design
- Sensor and actuator management
- Operating modes and state transitions
- Obstacle detection and safety mechanisms
- Separation of control logic and hardware interfaces

The laboratory environment included a graphical simulator and an interface for a physical door system.

---

## 2. Raspberry Pi Pico W — Network Communication

**Technologies:** C, Raspberry Pi Pico W, Wi-Fi, UDP

Embedded networking project involving the configuration of a Raspberry Pi Pico W for wireless communication.

**Main topics:**
- Wi-Fi initialization and configuration
- Station mode and network connection
- IP address retrieval
- Integration with a client/server UDP communication architecture

My work focused on the Wi-Fi setup component.

---

## 3. TRIAC Control — EET-2

**Technologies:** XMC1100, C/C++, PlatformIO, Interrupts

Embedded control laboratory involving TRIAC switching and synchronization with an AC zero-crossing signal.

**Main topics:**
- Hardware interrupts
- Zero-crossing detection
- Polling versus interrupt-driven processing
- Timing and synchronization
- Microcontroller-based actuator control

My work included the interrupt-based zero-crossing detection task.
